# 🖼️ Horizontal Scrollable Image Gallery

## 📌 About the Project

This project is a simple and attractive **Horizontal Scrollable Image Gallery** built using HTML and CSS. It displays multiple images in a horizontal row inside a parent container.

Users can scroll horizontally to explore images. The project uses CSS Flexbox to arrange image cards in a single row and `overflow: auto` to enable horizontal scrolling.

It also includes custom scrollbar styling, rounded image corners, and responsive image fitting using `object-fit: cover`.

## ✨ Features

- Horizontal image scrolling.
- CSS Flexbox layout.
- Multiple image cards in a single row.
- Custom scrollbar styling.
- Smooth and simple scrolling experience.
- Rounded image corners.
- Images automatically fit their containers.
- Mouse cursor interaction.

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Overflow Properties
